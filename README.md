# TaskFlow

## Descrição do Aplicativo

O TaskFlow é uma aplicação multiplataforma desenvolvida em Flutter com o objetivo de auxiliar usuários no gerenciamento de tarefas pessoais. O sistema permite o cadastro e autenticação de usuários, além do gerenciamento completo de tarefas através das operações de criação, visualização, edição e exclusão.

A aplicação foi desenvolvida utilizando Flutter e Dart, integrando autenticação e persistência de dados com Supabase, aplicando conceitos de desenvolvimento multiplataforma, organização de código, navegação entre telas e integração com banco de dados em nuvem.

---

# Funcionalidades Principais

- Cadastro de usuários
- Login de usuários
- Logout da aplicação
- Proteção de telas autenticadas
- Criação de tarefas
- Listagem de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Marcação de tarefas como concluídas
- Persistência de sessão do usuário
- Validação básica de formulários
